# Dictionary App
___________________________________________________________________
# Giới Thiệu
- Ứng dụng được viết bằng ngôn ngữ Java 
- Ứng dụng từ điển giúp cho người dùng có thể tra cứu Tiếng Anh một cách hiệu quả.


# Tính năng 
- Chương trình hỗ trợ thao tác tra cứu tìm kiếm cho người dùng. Ngoài ra còn có các chức năng thêm, sửa, xóa để người dùng thao tác trực tiếp vào dữ liệu từ điển.
- Chương trình cũng có một game nhỏ giúp người dùng ôn tập từ Tiếng Anh một cách hiệu quả hơn.
- Các chức năng của từ điển:
```sh
1 Thêm từ
2 Sửa từ 
3 Xóa từ 
4 Hiển thị toàn bộ từ vựng 
5 Tra cứu 
6 Tìm kiếm 
7 Game 
8 Nhập dữ liệu từ file
9 Xuất dữ liệu ra file 
```
